# CampusChef（キャンパスシェフ）

## 概要
ユーザが冷蔵庫にある食材をスマートフォンなどで撮影すると、AIが画像内の食材を自動的に検出し、その食材を使って作れる料理を提案する。

特に、一人暮らしの大学生が「冷蔵庫にある食材で何を作ればよいかわからない」という問題を解決することを目的としている。

画像認識AIと自然言語処理AIを組み合わせることで、食材の検出からレシピの推薦、調理手順の生成までを行うアプリを目指す。

## 想定ユーザ
* 自炊をしたいが、何を作ればよいかわからない大学生

* 冷蔵庫に残っている食材を有効活用したい人

* 食費を節約したい一人暮らしの学生

* 料理のレシピを簡単に検索したい人

* 食材を無駄にせず、食品ロスを減らしたい人

## 主な機能

### 1. 食材画像認識機能（実装済み・精度改善中）
- YOLOv8を使用して、画像内の食材を検出する。
- 検出した食材の位置をBounding Box（BBox）で可視化する。
- Grounding DINOとの比較実験を行い、検出精度の改善に取り組んでいる。

### 2. 食材一覧表示機能（検出結果の確認）
- 検出した食材名と信頼度スコアを取得する。
- 検出結果を画像上のBBoxとして表示する。
- 現在は食材の誤検出や検出漏れが課題となっている。

### 3. AIレシピ生成機能（実装済み）
- Qwen3.5-4Bを使用して、入力された食材情報からレシピを生成する。
- 料理名、使用する食材、調理手順、調理のポイントなどを日本語で生成する。
- 一人暮らしの大学生を想定し、安く簡単に作れる料理を提案する。

### 4. 食材検出とレシピ生成の連携（改善中）
- YOLOv8で検出した食材情報をQwenに渡し、レシピを生成する仕組みを目指している。
- 現在はYOLOv8の検出精度が十分ではなく、正しい食材情報をQwenに渡せない場合がある。
- 今後は食材検出精度の向上と、検出結果を確認・修正する機能の追加を検討している。

### AIモデル・API

- **YOLOv8（食材検出）**
  - 画像から食材を検出するために使用する。
  - 複数の食材データセットを使用してFine-tuningを実施した。
  - 学習したモデルの検出精度を比較・評価した。
  - 現在は、冷蔵庫内の食材を正確に検出できない場合があることが課題となっている。

- **Grounding DINO（食材検出・BBox生成）**
  - テキストで指定した食材を画像から検出できるモデル。
  - YOLOv8との比較実験を実施した。
  - 指定するテキストによって検出結果が変化することを確認した。
  - 今後はBounding Box（BBox）を生成し、YOLOv8の追加学習用データとして活用することを検討している。

- **Qwen3.5-4B（レシピ生成）**
  - 当初は画像から食材を認識するために使用したが、誤認識などの問題が発生した。
  - 一方で、食材情報を入力すると、料理名、必要な食材、調理手順などを含むレシピを生成できることを確認した。
  - そのため、現在はQwenをレシピ生成モデルとして活用している。
  - 今後はYOLOv8で検出した食材情報をQwenに渡し、食材認識からレシピ生成までの連携を改善する予定である。

- **Stable Diffusion 3.5 Medium（合成データ生成）**
  - YOLOv8の食材検出精度を向上させるため、食材を含む冷蔵庫の合成画像を生成する実験を行った。
  - 今後は生成した画像にGrounding DINOを適用し、食材のBounding Box（BBox）を作成する。
  - BBoxとラベルを確認・修正した後、YOLOv8のFine-tuning用データとして活用する。
  - 実画像のみで学習したモデルと、合成データを追加したモデルの検出精度を比較する予定である。


## 入力と出力

### 入力

* 食材の画像（JPEG / PNGなど）

### 出力

* AIが検出した食材名

* 食材の位置を示すBounding Box

* 食材検出の信頼度スコア

* おすすめ料理の一覧（実装予定）

* 必要な食材と不足食材（実装予定）

* Qwenが生成した料理名、使用食材、調理手順、調理のポイント



## 工夫したい点

* **食材検出の精度向上**
    * YOLOv8とGrounding DINOの検出精度を比較する。
    * 誤認識が発生する原因を調べ、モデルの改善を行う。
* **Fine-tuning用データの改善**
    * Grounding DINOを使用して食材画像のBBoxを生成する。
    * 生成したBBoxを確認・修正し、YOLOv8の追加学習に利用する。
    * 合成データを利用して学習データを増やすことも検討する。
* **撮影方法の改善**
    * 冷蔵庫の中で撮影した場合と、食材を取り出して撮影した場合の違いを調べる。
    * 照明、撮影角度、食材の重なりによる影響を確認する。

## 現在の課題

### 1. 食材検出の精度向上
- YOLOv8を使用して食材検出機能を実装したが、一部の食材を正しく認識できない問題がある。
- 特に、冷蔵庫内では食材の重なり、照明、撮影角度などによって検出精度が低下する場合がある。
- 学習データと実際の冷蔵庫画像の違い（Domain Shift）に対応し、検出精度を改善する必要がある。

### 2. YOLOv8とGrounding DINOの比較・改善
- 同じ画像でも、YOLOv8とGrounding DINOで検出結果が異なることを確認した。
- Grounding DINOでは、指定するテキストによって検出結果が変化する。
- 今後は、Grounding DINOで生成したBounding BoxをYOLOv8の追加学習に活用し、検出精度の改善を検討する。

### 3. YOLOv8とQwenによるレシピ生成機能の連携
- Qwenを使用したレシピ生成機能は実装済みであり、食材情報を入力するとレシピを生成できる。
- しかし、YOLOv8が画像内の食材を正しく検出できない場合、Qwenに必要な食材情報を渡すことができない。
- そのため、画像からの食材検出とレシピ生成を安定して連携させることが現在の課題である。
- 今後は、食材検出精度の改善に加え、検出結果を確認・修正してからレシピを生成できる仕組みも検討する。

### 4. 学習データの改善
- Stable Diffusion 3.5 Mediumを使用して合成画像を生成する実験を行った。
- 今後は、合成画像にGrounding DINOを適用してBounding Boxを生成し、YOLOv8の追加学習データとして活用する。
- 実画像のみで学習したモデルと、合成データを追加したモデルの検出精度を比較する必要がある。
